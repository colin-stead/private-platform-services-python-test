     - pytest runs on the host (.venv, Python 3.14, pytest installed); Mongo is

       can't make it use "Tests".
       Approach: pytest starts its own in-process Tornado server (port 7051) in
       a background thread, after setting
       os.environ to point at the "Tests" DB. The 7050 server/"Rewards" DB are
       never touched. No docker/compose changes.
     - MONGODB_URI (used by test_connection) is not set anywhere; it will be
       replaced by the shared config.
